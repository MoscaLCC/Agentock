# Quadro fundamental

## Valorização
- Compara P/E, EV/EBITDA e P/B com os peers (`vs_peers`) quando existir; prémio > 30% sem crescimento superior → cara.
- DCF: `upside_pct` > +20% → sinal de barata; < −20% → cara. Se `terminal_share_pct` > 75%, o DCF vale pouco.
- Nos EUA, se o DCF próprio e o do FMP divergirem muito, diz que a valorização é **indeterminada** pelo DCF.
- FCF yield > 5% é atrativo; < 2% exigente.

## Qualidade
- Margens operacionais estáveis ou a subir e ROE > 15% → alta. Margens a cair 3 anos seguidos → baixa.
- FCF positivo e próximo do lucro → qualidade dos lucros.

## Crescimento
- Receita: CAGR > 10% forte; 3–10% moderado; 0–3% fraco; < 0 negativo. Confirma com o YoY mais recente.

## Risco de balanço
- Dívida líquida/EBITDA > 3 ou cobertura de juros < 3 → alto. Caixa líquida (dívida líquida < 0) → baixo.
- Bancos e seguradoras: estes rácios não se aplicam — diz isso e não penalizes.

## Score
- +2 barata + alta qualidade + crescimento; +1 dois destes; 0 misto; −1/−2 espelho.
